# v2 results — calibration and selective policy

**Evaluation unit:** FEVER claims (1,998 test claims).
**Test pass:** spent once after freezing calibration, policy, and flag.
**Serving:** learned detector offline; fixed rule served.

## Protocol

- Base verdict model: frozen v1 hybrid combiner.
- Calibration: temperature scaling fitted on validation, cross-fitted for selection.
- Selective policy: class-specific calibrated thresholds with abstention.
- Coverage flag: strict-retrieval-failure diagnostic fitted on train and evaluated
  on test as part of the frozen gate set.
- Test thresholds, temperature, and flag were frozen before the pass.

## Gate outcome

| Gate | Threshold | Result |
|---|---:|---|
| Macro-F1 | >= 0.697 | Pass |
| ECE | <= 0.05 | Pass |
| Brier | not worse than raw | **Fail** (0.39725 vs 0.39656) |
| Verifiable precision | >= 0.94 | Pass |
| Verifiable coverage | >= 0.75 | Pass |
| Overall precision | >= 0.70 | Pass |
| Coverage-flag AUROC | >= 0.75 | **Fail** (0.73374) |

**Promotion:** failed. The learned detector stayed offline and the coverage flag
was omitted from serving.

## Interpretation

- Calibration reduced ECE, but the tiny Brier increase still failed the written gate.
- The policy is strong on claims whose gold label is verifiable, but this number
  conditions on gold and is unavailable at inference time.
- NEI claims remain the dominant accepted-error source: many are answered
  confidently and incorrectly.
- The coverage flag enriched errors but did not meet its AUROC stability bar.
