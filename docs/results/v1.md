# v1 results — claim-level baseline

**Evaluation unit:** FEVER claims (1,998 test claims).
**Test pass:** spent once for the learned Stage 5 combiner.
**Serving:** fixed 0.7/0.95 rule; learned model offline.

## Protocol

- Fit: 3,000 balanced FEVER train claims.
- Select: 999 balanced validation claims.
- Report: 1,998 balanced test claims.
- Retrieval: hybrid BM25 + dense BGE with RRF.
- Verification: DeBERTa-v3-base-MNLI + BGE similarity.

## Headline results

| System | Test macro-F1 |
|---|---:|
| Fixed rule | 0.6328 |
| Learned hybrid combiner | **0.7020** |
| Learned dense combiner | 0.7015 |
| Learned BM25 combiner | 0.6821 |

Ablation on the learned hybrid model:

| Variant | Test macro-F1 |
|---|---:|
| Full 30-feature model | **0.7020** |
| Remove NLI features | 0.5465 |
| Remove retrieval-score features | 0.7006 |
| Remove similarity features | 0.6980 |
| Remove claim-shape features | 0.6932 |
| NLI only | 0.6733 |
| Retrieval only | 0.4296 |
| Similarity only | 0.4567 |

NLI is the load-bearing component. The learned model's gain over the fixed rule is
paired and statistically significant, but the model remains offline because the
serving gates are broader than macro-F1.

## Oracle evidence reference

On FEVER verifiable claims with gold evidence, NLI-concat two-way accuracy is
**94.3%** (F1 **0.943**). That is an evidence upper bound, not an end-to-end result.

## Interpretation

- The learned combiner is better on the measured task.
- The fixed rule is safer to serve because it has no fitted decision layer.
- The remaining error is dominated by evidence coverage and NEI handling, not by
  NLI on claims with complete evidence.
