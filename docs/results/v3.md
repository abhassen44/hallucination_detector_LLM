# v3 results — calibration and answerability stop

**Evaluation unit:** FEVER validation claims (999).
**Test pass:** **not spent**. v3 stopped before P4 because the validation gates were
unreachable.
**Serving:** learned detector offline; fixed rule served.

## Interpretation

- The calibration work was a genuine validation improvement.
- The answerability head did not separate NEI from verifiable claims strongly
  enough to justify a test pass.
- No test predictions exist, so v3 has no test result.
